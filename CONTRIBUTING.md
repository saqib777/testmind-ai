
# Contributing to TestMind AI

Thank you for your interest in contributing.

---

## Getting Started

```bash
git clone https://github.com/saqib777/testmind-ai
cd testmind-ai
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Add your GROQ_API_KEY to .env
```
